# HoloCubic 网页手柄

在设备原有 HID Pad 1.1.1 Lua 服务上增加网页接管，版本 1.1.4。不需要修改固件。保留原有蓝牙驱动、配对、校准和按键映射。

打开 `http://设备IP/hidpad/remote/`，点击“接管手柄”。支持方向键、A/B/X/Y、LB/RB、L3/R3、View/Menu、Share、Home 全部 16 个按键，以及多指组合、长按和松开。电脑方向键或 WASD 控制方向，J 为 A，K 为 B，L 为 X，I 为 Y，Q/O 为肩键 LB/RB，F/G 为 View/Menu，Esc 为 Home。L3/R3 为摇杆按下，View 对应 SELECT，Menu 对应 START；L3/R3 默认绑定 E/U，与上方 LB/RB 的 Q/O 对应；Share 默认无键盘绑定，可自行改键。页面也能选择并打开设备应用，或返回启动器。

点击“键盘改键”，再点击一个手柄按钮，按下要绑定的键盘键。每个按钮下方显示当前绑定，自动保存在当前浏览器（同一设备 IP）；改键无需先接管。一个键只能对应一个按钮，重新绑定会从其他按钮移除该键。支持取消本次绑定、清除该键绑定和恢复默认。点击“完成改键”后恢复正常操作。改键期间会释放并暂停游戏输入，按键区也支持用 Tab、Enter 选择要修改的按钮。浏览器不允许本地保存时，仍可在当前页面会话中使用。

接管时将网页输入发布到现有 `ble-main` 手柄通道，屏蔽实体手柄输入。退出后恢复实体手柄。页面失焦、进入后台或关闭会主动释放；停止心跳后约 8 秒自动解除接管。网络变慢时页面不会禁用按键，租约断了会自动接回并补发当前按住的键。另一个页面点击接管可取得控制权。短点击至少维持 110ms，避免应用轮询漏掉。

已接入 `controller.state("ble-main")` 或对应订阅的应用可直接响应；仅处理机身按键的应用需单独适配。黄金矿工：A 放钩，↓ 使用炸药，SELECT 退出；商店左右选商品、A 购买、↓ 下一关。

## 更新与恢复

这是已安装 HID Pad 的更新包，保留设备原有 `modules/hidpad.so` 和 `config.json`。复制 package 中的文件到 `/sd/apps/hidpad/`，重启手柄服务。服务设置页也增加了网页手柄入口。不要用官方商店更新覆盖此版本，否则网页功能会被移除。

需要回退时，用更新前的官方 HID Pad 文件覆盖并重启服务。

## 实现与验证

`remote_input.lua` 管理单页面控制权、严格递增序号、按键状态和超时释放；`main.lua` 将其覆盖到现有手柄发布流程并注册网页接口，100ms 定时检查失联。网页按序发送输入，空闲时每 400ms 续约（只允许一个请求在途），按键变化会立刻发送。接管期间不再额外查询应用列表。网络变慢或租约中断时，页面保持可操作，并自动重新接管、补发当前按住的键。切到后台或关闭页面才会松开。输入不会写入蓝牙配对和映射设置。

`python tests/test_remote.py` 用 Lua 5.3 检查接管、组合按键、过期和乱序请求、竞争页面、断线释放、实体手柄恢复以及完整服务的 HTTP 到 controller.publish 流程。前端通过 `node --check package/remote.js` 检查语法，并在设备上验证实际控制。
