# 黄金矿工 1.2.9 安装说明

作者：游侠173

## 安装哪一份

使用 [`src/dist/黄金矿工_1.2.9_完整安装包.zip`](../dist/黄金矿工_1.2.9_完整安装包.zip)。这是完整包，首次安装和覆盖更新都使用这一份，不需要依次安装旧版本。1.2.8 安装包仅保留为上游历史版本。

`gold-miner/package/` 是同一份安装包的运行文件，含 `app.info`、`info.html`、`main.lua` 和资源。复制时将其中内容放入设备应用目录，不要额外嵌套 `package` 目录。

1.2.9 将图片、字体声明改为应用相对路径，并根据 `app.current().entry` 动态转换为固件所需的 SD/LVGL 路径；不再依赖其他应用的字体。安装目录可以改名，诊断路由也随应用变化。系统语言仍读取设备的公共设置文件 `/sd/apps/settings.json` 或 `/sd/settings.json`，它们不是应用资源。

## 安装步骤

1. 如果已安装过，先备份设备 `/sd/apps/gold_miner/`。
2. 解压完整安装包，将 `gold_miner` 文件夹复制到 SD 卡的 `apps` 目录，允许覆盖同名文件。使用网页文件管理时，上传到 `/sd/apps/gold_miner/` 并保留子目录。
3. 最终路径应如下，避免多套一层 `package`、`安装文件` 或 `gold_miner` 文件夹：

```text
/sd/apps/gold_miner/
├── app.info
├── main.lua
├── main.png
├── info.html
├── assets/    游戏图片，全部复制
└── font/      中文字体与许可证，全部复制
```

4. 刷新启动器应用列表；没有显示时重启设备，打开「黄金矿工」。

本包包含最新矿工、木桶 TNT、小猪方向素材与帧率优化，不需要另外装素材补丁。使用机身按键无需手柄服务；手柄输入可使用设备已安装的兼容服务，本仓库不再提供 HID Pad。

## 基本操作

| 操作 | 机身按键 | 手柄 / 网页手柄 |
| --- | --- | --- |
| 开始、放钩、确认、购买 | 上 | A / START / 上 |
| 商店选择商品 | 左 / 右 | 左 / 右 |
| 使用炸药、商店下一关 | 下 | 下 |
| 退出 | HOME | View（SELECT）/ Home |

16 关挑战，每关 60 秒。前 8 关保持原来的目标，第 9 关起石头、炸药桶和钻石猪更多。累计财富达到目标才能过关，购物会扣除财富。抓到重物时可使用炸药，关间购买道具强化。
